# AI-Powered Code Review Assistant

## 📌 Overview
The AI-Powered Code Review Assistant is a comprehensive web-based tool designed to automate and enhance pull request analysis. By seamlessly integrating LLMs with GitHub, this assistant provides real-time, context-aware feedback on code diffs, significantly accelerating the software development lifecycle and improving code quality.

## 🚀 Features
- **Automated PR Analysis:** Analyzes pull requests automatically to identify potential bugs, vulnerabilities, and code quality issues.
- **Real-Time Diff Extraction:** Integrates directly with GitHub APIs to fetch and process code changes in real-time.
- **Context-Aware Feedback:** Utilizes optimized LLM prompts (powered by MistralAI) to generate accurate, relevant, and actionable code review comments.
- **Full-Stack Architecture:** Features a robust Node.js backend and a responsive, user-friendly frontend.

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js
- **AI/LLM:** MistralAI, Python
- **Integrations:** GitHub API
